# 티스토리 스킨

`machamy.tistory.com` 에 적용한 자체 스킨의 정본이다.

| 파일 | 무엇 |
|---|---|
| `skin.html` | 스킨 HTML. 티스토리 치환자와 동작 스크립트 |
| `style.css` | 스타일. 토큰 + 레이아웃 프리셋 12종 |
| `skin.original.html` · `style.original.css` | 갈아엎기 전 원본(베이직 타입). 되돌릴 때 쓴다 |

## ⚠️ 여기에 두는 이유

**티스토리에서 스킨을 바꾸면 HTML·CSS·업로드 파일이 전부 초기화되고, 되돌릴 수단이 없다.**
관리 화면 안에는 판본 기록이 남지 않는다. 그래서 정본은 이 저장소에 둔다.
티스토리 쪽은 배포된 사본일 뿐이다.

## 적용하는 법

관리 → 꾸미기 → 스킨 편집 → `html 편집` → HTML/CSS 탭에 각각 붙여넣고 `적용`.

## 스킨이 하는 일

- 카테고리 이름을 색으로 가른다(알고리즘·ECS·유니티·간단 코드·일상). 목록에서 글 종류가 먼저 보인다.
- **긴 글에만** 눈금 레일·목차·진행률이 붙는다(소제목 3개 이상 그리고 2,500자 이상).
  백준 풀이처럼 짧은 글에는 안 붙는다.
- 글자 수와 읽는 시간을 본문에서 직접 센다(한국어 기준 분당 500자).
- 코드 블록 복사 버튼. 본문 이미지 확대. 소제목 앵커.
- 레이아웃 프리셋 12종을 머리 버튼으로 전환한다. 고른 값은 브라우저에 남는다.
- 다크 모드. 그리기 전에 결정해서 흰 화면이 번쩍이지 않는다.
- mermaid 다이어그램을 렌더한다.

## 밟았던 함정

여기 적힌 것은 전부 실제로 한 번씩 당한 것이다.

- **모바일 방문자는 이 스킨을 못 볼 수 있다.** 티스토리가 모바일 UA 를 `/m/` 경로의 자체 모바일
  스킨으로 리다이렉트한다. 관리 → 꾸미기 → 모바일에서 **"티스토리 모바일웹 자동 연결"을 꺼야** 한다.
  좁은 뷰포트로 데스크톱을 줄여 보는 것으로는 이 사실이 드러나지 않는다.
- **티스토리 검색은 쿼리스트링이 아니라 경로다.** `/search?search=x` 는 언제나 0건이고
  `/search/x` 라야 결과가 나온다.
- **`[##_image_##]` 는 이미지 주소 문자열**이다. `<img src="...">` 로 감싸야 그림이 나온다.
  그냥 두면 URL 이 글자로 찍힌다. `[##_list_image_##]` 도 같다.
- **에디터가 만든 인용은 배경 이미지다.** `blockquote[data-ke-style]` 에 큰따옴표 SVG 가
  `background-image` 로 깔리고 `color:#333` 이 고정된다. `content:none` 으로는 안 지워지고,
  다크 모드에서 글자가 안 보이게 된다. 배경과 색을 직접 덮어야 한다.
- **`hidden` 속성은 클래스 규칙에 진다.** 미디어쿼리에서 `display` 를 주는 요소는 `hidden` 이어도
  보인다. `[hidden]{display:none!important}` 를 못박아 둔 이유다.
- **highlight.js 의 언어 자동 추측은 자주 틀린다.** 이 블로그의 C++ 블록이 `routeros`·`prolog`·
  `arduino` 로 태깅된 것을 확인했다. 그래서 언어 라벨은 에디터가 붙인 `data-ke-language` 가
  있을 때만 보여준다. 추측을 표시하면 잘못 가르친다.
- **헤딩 id 를 순번으로 만들면 안 된다.** 연재 중간에 소제목을 하나 끼우면 그 글로 걸어 둔
  기존 앵커가 전부 다른 절을 가리킨다. 제목 텍스트에서 만든다.
- **mermaid 는 나중에 렌더되며 문서 높이를 바꾼다.** 눈금 레일과 진행률을 처음 한 번만 계산하면
  다이어그램이 많은 글에서 어긋난다. `ResizeObserver` 로 다시 잰다.

## 아직 안 한 것

- 프리셋을 티스토리 "스킨 옵션"으로 승격하는 것. 그러려면 `index.xml` 이 필요한데 웹 편집기로는
  못 올리고, `index.xml` 이 바뀌면 스킨 설정이 초기화된다. 지금은 브라우저에 저장하는 방식이다.
- 시리즈 네비게이션. `<s_article_prev>`/`<s_article_next>` 는 **같은 카테고리 안에서만** 동작한다.
  7편 이후 글들에 카테고리가 없어서 다음 글 링크가 끊긴다. 카테고리를 붙이는 게 선행이다.
- 목록 썸네일. 글에 대표 이미지를 지정하지 않아 공유 미리보기가 티스토리 기본 로고로 나간다.
